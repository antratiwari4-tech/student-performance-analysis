# student-performance-analysis
A beginner-friendly Data Science project using Python, Pandas, and Matplotlib to analyze student performance, calculate average marks, and visualize results.

# Student Performance Analysis

## About
A beginner-friendly Data Science project that
analyzes sample student marks using Python.

## Tools Used
- Python
- Pandas
- Matplotlib

## What This Project Does
- Stores student marks in a DataFrame
- Calculates average marks
- Identifies the highest average
- Visualizes results using a bar chart

## Learning Outcomes
- Data handling with Pandas
- Basic statistical calculations
- Data visualization
